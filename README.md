## Overview

Riffer generates random melodic and rhythmic patterns based on configurable scales, note ranges, velocity curves, and density, producing fresh MIDI riffs on demand or in sync with a DAW clock.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Audiomodern Riffer** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Scale Lock** | Generate riffs locked to any of 40 built-in musical scales |
| **Density Control** | Adjust note density from sparse arpeggios to dense runs |
| **Rhythm Grid** | Configurable step grid with swing and accent probability per step |
| **MIDI Output** | Route generated patterns to any instrument via MIDI output buss |
